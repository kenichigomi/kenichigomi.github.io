Celebrating a successful deployment and future thoughts

July 29, 2026 2-minute read
Kenichi Gomi
Devlog • English

Cheers! This website got deployed to GitHub today on July 29, 2026.

The main purpose of this website is to host my resume and my contact information. I was on a call yesterday and my friend asked why I didn’t just embed a resume so that it could be downloaded, but I think it looks cleaner this way. Maybe I’ll implement a link or a page sometime for downloadables.

I also wanted to have a place to dump some thoughts, kind of like a substack. I created a private photography instagram account which I treat as a digital diary of sorts, but since this is public the words you see will be slightly filtered. I also don’t plan on posting daily.

If you’ve been clicking around the site for a while, I think you may have noticed that there is a translation feature. The way the translations work is actually a bit annoying, and I have to manually translate each page in Japanese. However, this is a good way to practice so although you may not see all pages get translated (especially the blog posts) I hope to make sure that all content is equally accessible.

Well, I think that’s it for now. Right now I’m working on translating my resume to Japanese, and I think I’ll also try playing around with the tags (I want to see if I tag a Japanese page with a tag originally assigned to an English page, how they interact).
